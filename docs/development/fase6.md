# Fase 7

`admiral-harbor` es el portal de cliente.

Propósito:

- catálogo.
- contratación.
- estado de apps del cliente.
- backups y restore desde la perspectiva comercial.

Límites:

- no administra infraestructura.
- no toca Podman ni systemd.
- no sustituye a `admiralctl` ni a `admiral-flagship`.

Estado:

- el proyecto existe, pero debe tratarse como pre-alpha.
