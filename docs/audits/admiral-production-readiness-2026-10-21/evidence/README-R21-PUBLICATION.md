# R21 evidence archive publication

This is historical R21 evidence, not a current release candidate. The archive contains candidate/build records and six-cell runtime result artifacts.

- Archive: `rc6-e5-r21-public.tar.gz`
- SHA-256: `90acb1cc825c842e86aa9bcd3ffd6d1f2acfbae33a5f3d448d7b7747fab12ae5`
- The archive includes a `PUBLIC-SHA256SUMS` manifest.
- Harness and fixture files with extensions `.sh`, `.py`, `.yaml`, `.yml`, and `.diff` are excluded because they may contain generated test credentials or local harness details. Their paths and original SHA-256 values are recorded in `EXCLUDED-TEST-INPUTS.tsv`.
- The archive does not claim that R21 is the current candidate. A later Fleet product change requires a new candidate and a new six-cell matrix.
