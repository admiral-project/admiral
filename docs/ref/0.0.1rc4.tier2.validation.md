## Fedora 44 package-manager probe

The official Fedora 44 GenericCloud builder was updated with
`dnf update --refresh`; afterward `dnf check-update --refresh` returned 0. The
builder reported DNF5 5.4.5, Python 3.14.7, OpenSSL 3.5.8, and kernel
`7.2.7-200.fc44.x86_64`.

With the local repository and Admiral COPR enabled, a DNF5 dry-run selected
all six listed `.el10` RPMs from `admiral-local`. Fedora supplied Caddy
`2.10.2-9.fc44`; Admiral COPR supplied the Fedora build of
`python3-flask-alembic`. The full 85-package dependency transaction resolved;
`--assumeno` then intentionally canceled it before installation. This is a
package-resolution probe, not an installer scenario.

The active validation repository is served on the libvirt network at
`http://192.168.122.1/el10/x86_64/`. Each RPM checksum matches this report.
The previous Tier 1 repository candidate is archived at
`/var/lib/admiral-rpm-repo/archive/tier1-initial-0.0.1rc4`.
